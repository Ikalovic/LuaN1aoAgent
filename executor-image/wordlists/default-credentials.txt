# Vendor / product default credentials as `username:password` pairs.
#
# Format is exactly what `hydra -C <file>` consumes, so a single file can be
# thrown at any service hydra speaks:
#
#   hydra -C /opt/luanniao/wordlists/default-credentials.txt -f -t 4 ssh://TARGET
#   hydra -C /opt/luanniao/wordlists/default-credentials.txt -f -t 4 TARGET ftp
#
# A pair with nothing after the colon is an *empty* password, which is a real
# vendor default (MySQL root, MikroTik admin, MSSQL sa) and not a typo.
#
# Rule from templates/skills/default-credentials/SKILL.md: fingerprint the
# product first and try the matching rows, rather than feeding this whole file at
# an unidentified login form. The file exists so the credentials are one command
# away once the product is known, not as a substitute for identifying it.
#
# Blank lines and lines starting with # are stripped at image build time.
