# 青玄：首页与登录页设计

日期：2026-09-15。用户已选择视觉草稿 **B：品牌与概览**，明确要求保留独立登录界面，并授权完成设计稿后直接实现。本稿为本次实现依据。

## 1. 范围与入口

- 新增公开展示首页，首页不替代工作台总览或登录页。无查询参数的根地址默认展示首页，已登录用户也能主动返回首页。
- 保留现有登录、注册、退出、角色权限和后台认证接口，不新增认证机制。
- 工作台与态势大屏仍需登录。未登录时先进入独立登录页，成功后返回原目标；已有有效会话则直接进入。
- 保持既有 `?view=...&runtimeDir=...` 深链接有效，不因新增首页丢失运行、节点或图表选择。
- 此规格补充前端总规格：新增首页入口，并允许首页复用已有登录品牌背景；工作台和大屏的其他设计不变。

## 2. 首页视觉与内容

采用用户选择的 B 版构图：首屏全幅石墨材质背景，左侧直接排版品牌内容，下一段为浅灰绿色的产品概览区域。不做文字与图片分置的卡片布局，不把首页套入工作台侧栏。

首屏从上到下：

1. 顶部青玄标识，右侧工作台、态势大屏与登录入口。已登录时登录入口改为进入工作台。
2. 主标题 **青玄**，副标题 **自动渗透 agent**。
3. 一行介绍：**以自主规划与多智能体协作，贯通资产发现、验证与证据追溯。** 移动端自然换行。
4. 两个主要操作：进入工作台、态势大屏。
5. 三项简短概述：自主规划、资产感知、证据追溯。仅使用项目已有能力，不展示虚构运行数或安全效果承诺。

概览区域标题为“资产与证据，串起执行全程”，通过工作台、态势大屏两个标签切换实际产品截图。截图使用本地演示数据，并在图下注明；不读取或公开真实运行数据。截图完整呈现、保持比例，不使用模糊、遮罩或装饰性设备外框。

页脚以小字明确显示：**本项目基于 LuaN1aoAgent 改造而成。** 其中项目名链接到 `https://github.com/SanMuzZzZz/LuaN1aoAgent`，新窗口打开并设置 `noopener noreferrer`。青玄始终是页面主品牌，上游名称只用于来源说明。

标题使用本地得意黑，英文及技术性短标签使用本地 Chakra Petch；正文保留清晰的中文无衬线字体。保持字距为 0，字号通过明确断点调整，不用视口宽度缩放。石墨、银白、薄荷青与浅灰绿共同构成页面，不新增装饰光球或厚重机械边框。

## 3. 独立登录页

- 与首页共用青玄标识、字体和品牌材质背景；登录表单是独立页面，不嵌在首页概览中，也不以弹窗替代。
- 采用居中的单列轻量表单，桌面宽度约 390px，移动端按可用宽度布局。表单标题使用适合紧凑区域的字号，不使用首页巨型标题。
- 保留用户名、密码、密码显隐、登录及注册标签；注册继续使用现有显示名、用户名、密码和确认密码字段及规则。
- 保留提交中禁用、必填校验、错误提示及错误关闭，不新增没有后台支持的找回密码、第三方登录或记住密码开关。
- 提供返回首页入口。原有语言及主题切换继续可用，浅色表单适配现有主题，不对位图背景反相。首页与登录页的展示不改写工作台主题偏好。
- 登录失败时保留目标页面及用户名；不将密码或凭据写入 URL、浏览器持久化存储或日志。

## 4. 路由与数据边界

沿用查询参数导航，不引入新的路由框架。公开页面由独立的入口状态解析，不把首页、登录混入现有图谱 `ViewKey`。

| 地址形态 | 行为 |
| --- | --- |
| `/` 或 `?page=home` | 展示公开首页 |
| `?page=login` | 独立登录页，默认目标为工作台总览 |
| `?page=login&view=wallboard&runtimeDir=...` | 登录后进入指定运行的大屏 |
| 既有 `?view=...&runtimeDir=...` | 已登录展示原业务页面；未登录则补充登录入口状态，保留原业务参数 |
| 仅含 `runtimeDir` 的旧地址 | 延续原行为，目标为该运行的工作台总览 |

登录成功移除入口参数 `page=login`，对业务参数使用现有导航解析规则。返回目标仅由内部视图白名单和既有业务参数构成，不接受外部跳转地址。浏览器前进、后退及直接刷新均应保持当前页面与目标一致。

`AuthRoot` 负责首页、认证状态和业务应用的分流；首页独立组件只接收会话摘要及内部入口，不调用运行接口。会话检查可以进行，但公开首页不等待检查完成才能显示，也不挂载 `App`、`useRuntimeDashboard` 或审批轮询。业务应用按需加载，避免首页与登录页加载图表和三维场景模块。

复用现有 `useAuth`、登录注册 API 和未授权处理。会话过期时返回登录页并保留目标；接口异常在登录表单显示可重试错误，公开首页仍可查看。进入业务应用后继续复用现有导航和权限判断。

工作台增加可返回首页的入口，离开前沿用已有未提交编辑确认。不会因为跳转到首页而停止正在后台运行的任务，但当前页面的轮询和监听应随卸载释放。

本阶段无需新增 AI 生成图片。用户此前授权的生成 API 仅在确需补充主视觉时使用，不将凭据写入源码、页面、设计文档或素材清单。截图仅允许包含测试数据，不带真实目标、账户、凭据或内部运行目录；不能让 AI 生成的界面冒充实际产品截图。

首页截图区域延迟加载，图片采用 WebP、固定宽高比并提供失败回退。背景加载失败时使用一致的中性底色，保证标题与按钮仍可用。新增素材来源、尺寸和发布路径补入现有素材清单。

## 6. 轻量验收

- 检查未登录、已登录和会话失效下的首页、登录、工作台、大屏跳转；覆盖登录后恢复深链接与浏览器后退。
- 确认公开首页不请求运行、审批等业务数据；现有注册、权限和登录错误提示保留。
- 在桌面、手机和 4K 尺寸查看首页与登录页：无横向溢出、文字遮挡或图片缺失，首页首屏露出下一段内容；表单与截图可正常操作。
- 执行前端构建及入口相关的少量定向测试，不扩展为全项目审查、完整后端测试或长期性能测试。

本次仅新增首页、衔接登录和返回入口，不重做大屏、业务图谱、任务执行或后台接口。
