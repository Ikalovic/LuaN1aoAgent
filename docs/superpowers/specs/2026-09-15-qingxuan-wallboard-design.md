# 青玄 自动渗透agent：独立展示大屏设计

日期：2026-09-15。源码基线：`597509c`，已合入远端 `60a1753`。

状态：新增设计规格，供实施前审阅。用户要求增加专门用于展示的大屏页面；本文明确其布局、交互、数据和资源要求，尚未实现页面。

关联主规格：[青玄前端重构设计](2026-09-15-qingxuan-frontend-design.md)。品牌、数据口径、权限、图谱语义和主题基础沿用主规格；本规格补充独立展示场景。继续采用 Superpowers brainstorming 的设计与审阅流程。

## 1. 展示目标

大屏用于会议演示、项目展示和现场运行观察。观看者可以在几秒内看清产品名称、当前目标、资产与发现规模、关键关联路径和运行进展，不需要操作完整工作台。

页面名称为“态势大屏”，品牌完整名称为 **青玄 自动渗透agent**。它是同一应用中独立的只读展示页面，拥有专门布局，复用现有运行数据。工作台总览仍负责日常操作与深入分析。

| 维度 | 工作台总览 | 态势大屏 |
| --- | --- | --- |
| 场景 | 近距离反复操作、筛选、检查 | 远距离观看、讲解、持续展示 |
| 布局 | 导航、工具栏、可滚动内容与详情 | 无常驻侧栏，主图占中心，少量辅助区 |
| 信息 | 完整状态、筛选和操作入口 | 当前运行关键指标、短结论和近期变化 |
| 控制 | 任务控制、深入业务页面 | 全屏、暂停展示更新、刷新和返回工作台 |
| 视觉 | 紧凑文字与表格 | 更明显的字号层级、稳定分区、清晰拓扑 |

独立浏览器页与 Fullscreen API 是两种能力：不用浏览器全屏也能直接打开大屏；用户点击后才请求浏览器全屏。不新增独立后端部署、不新增公开匿名分享链接。

## 2. 入口与运行上下文

- 新增 `view=wallboard`，与主规格的 `runtimeDir`、`range`、`from`、`to` 共用解析。
- 顶栏增加带 Tooltip 的 `Monitor` 图标入口，当前运行加载有效后可打开。点击在新标签打开，使用 `noopener`，原工作台保持当前视图；浏览器不允许打开时提供同页链接。
- 新标签沿用同源认证 Cookie。登录过期进入现有认证流程，认证后恢复大屏 URL；不在 URL 附带 Cookie、令牌或秘密参数。
- 可选择已有历史运行展示其当前持久快照。历史快照标为“历史运行快照”，不命名为历史回放。
- 直接打开但缺少 runtimeDir 时，沿用 URL > 既有运行存储 key > 默认目录的选择规则；无法取得运行数据时显示运行选择与返回工作台入口，不展示模拟默认数据。
- 提供“返回工作台”入口，默认回到同一运行的 overview。通过节点“在工作台查看”进入 operation/reasoning/task 并携带 nodeId，符合主规格的真实引用规则。

## 3. 1920×1080 主布局

```text
+-------------------------------------------------------------------------+
| [品牌图形] 青玄 自动渗透agent       当前目标          运行状态 / 当前时间 |
+-------------------------------------------------------------------------+
|       主机       服务       漏洞发现       成功利用       任务完成       |
+-----------------+-------------------------------------+-----------------+
| 任务状态        |                                     | 重点发现        |
| 已完成/阻塞/... |                                     | 类型 / 短结论   |
|                 |         资产与关联路径主图          |                 |
| 角色最近活动    |                                     | 待处理事项      |
| Planner         |          [当前图类型标签]           | 阻塞 / 失败     |
| Executor        |                                     |                 |
| Observer        |                                     |                 |
+-----------------+-------------------------------------+-----------------+
|                     已加载事件趋势 / 最近关键事件                       |
+-------------------------------------------------------------------------+
| 当前快照范围 / 部分数据 / 更新时间         暂停状态       [展示控制条]   |
+-------------------------------------------------------------------------+
```

推荐外边距 24px、分区间距 16px。1920×1080 下分配：品牌区 64px、指标区 88px、底部趋势区 180px、状态区 28px，中心区使用剩余高度；五行之间共四处间距。中心三列为 `minmax(240px, 1fr) minmax(600px, 2.6fr) minmax(280px, 1.1fr)`，约 21%/55%/24%。

上述轨道为标准预设。远距预设改为品牌区 96px、指标区 128px、趋势区 240px、状态区 36px，正文行高同步提高，避免 64px 数值挤出指标区。侧栏可见条数按固定行高和实际容器高度减少，保持容器尺寸稳定；不通过压低字号强塞内容。

主图直接铺在连续背景上，不放入装饰预览卡；侧区使用细分隔线与小标题，避免一屏堆叠多个有阴影的大卡片。拓扑下方和左右区应形成清楚的阅读顺序。所有区域固定网格轨道，数据更新不改变尺寸。

右侧重点发现最多显示 5 条，每条最多两行结论和一行元信息；超出数量显示“另有 N 条已加载发现”。左侧角色区域固定四行，包含 Runtime 最近活动，明确属于事件摘要。下方最近关键事件最多显示 4 条，并配有实际时间；不显示工具原始输出。

顶部目标最多两行；范围摘要和超长内容通过展示控制条的目标详情查看，不继续向固定品牌区追加行数。主标题不会被运行名称挤掉。展示短名称可由操作者在控制条中编辑，仅为当前标签页的显示别名，不改写原始目标或保存到服务器。

## 4. 主视觉与动态规则

默认中央图为资产拓扑，展示 Host、Service、WebEndpoint 与实际关联关系。复用主规格的 Cytoscape、ELK、节点颜色、候选状态和证据语义，不引入 3D 场景或没有地理数据支持的世界地图。

大屏默认使用独立的深色主题配置，复用主规格的语义颜色；不改变工作台已保存的深浅偏好。标准/远距是字号与密度预设，不切换品牌色。

提供“资产 / 推理 / 任务” Segmented，默认资产。图切换只作用于中央画布，顶部指标仍表示当前运行快照。图类型在画布上方有持续可见的短标签，避免演示时误读。

资产图默认最多 60 个已加载节点，优先漏洞关联资产、选中节点及其一跳邻居。推理图以最近漏洞或成功利用的实际邻接关系为起点；没有相关节点时展示已有假设/证据或明确空状态。任务图沿用现有投影。图中没有的关系不生成示意连线。

用户可选择节点，弹出不超过 3 行的摘要，提供进入工作台的链接；大屏内不打开长报文、长证据内容或命令编辑器。选中节点和当前视口在刷新后保留；节点不在新快照时提示未载入，不自动选中别的对象。

新数据仅在稳定 ID 首次出现或实际状态变化时短暂突出 600–900ms；已有节点不随每次轮询重复闪动。数据批量到达时最多同时突出 5 个节点，其余变化进入计数。暂停、断线、历史快照以及 reduced-motion 下不播放表示实时活动的动画。

首版不自动轮换运行、不自动切换三图、不自动滚动长列表。可另提供默认关闭的“聚焦巡览”：每 15 秒聚焦下一个已显示的发现关联节点，最多 5 个候选；不跨图、不推断攻击路径。鼠标或键盘交互立即暂停巡览，操作者显式恢复。巡览是视角变化，不声称新事件发生。

## 5. 展示指标与数据边界

| 大屏信息 | 数据规则 | 受限时的展示 |
| --- | --- | --- |
| 主机、服务 | 已加载 operation 的对应类型按 ID 去重 | 标注已加载，不称全量资产 |
| 漏洞发现 | Vulnerability 且证据引用非空 | 无统一严重性时不显示“高危数量” |
| 成功利用 | Exploit 且 status=succeeded、证据引用非空 | 不把所有利用节点当成功 |
| 任务完成 | 已加载 completed / 非 archived Task | 未识别状态保留未知；分母为空不显示 100% |
| 角色最近活动 | 最新角色事件 | 不作为实时 Agent 在线心跳 |
| 待处理 | 阻塞、失败分组，管理员可显示当前运行审批数量 | analyst 不请求审批；不以 0 暗示无权限的数据 |
| 事件趋势 | 已加载事件按真实时间分桶，最多 60 桶 | 未覆盖范围不补零，部分记录标记持续可见 |

所有数据复用主规格的 `situation.ts` 与 coverage 传播规则。大屏不单独计算第二套“风险指数”。SQLite 图本身的 1200/2400 上限、700 事件窗口、报告/产物上限同样生效。

时间选择仅作用于事件趋势和近期事件，拓扑与上方资产/发现统计持续标明“当前快照”。选择旧运行不意味着能按任意时间恢复历史图。

当前时间由浏览器时钟显示并附时区，数据更新时间单独显示。时钟每秒更新只重绘时钟组件，不能触发图谱重建、数据请求或整页动画。

## 6. 刷新、暂停和异常

大屏单个标签只启动一套运行数据轮询，复用 `useRuntimeDashboard` 的请求结束后 5 秒刷新和隐藏标签暂停行为；与另一个工作台标签之间不新增跨标签轮询协调服务。

“暂停更新”冻结大屏当前快照，取消在途状态请求并阻止晚到响应覆盖画面，同时暂停聚焦巡览。暂停只改变展示，不停止 Agent 或后端任务；控制 Tooltip 写明含义。恢复立即进入自动刷新模式并请求一次，失败仍在请求结束后按 5 秒间隔重试；保留合理的图视口。手动刷新在暂停时仅取一次各来源数据，之后继续暂停；该次请求失败也保留暂停并显示局部错误。

冻结范围包括运行展示状态、指标、图谱、事件、coverage 和可见审批计数；各来源请求均服从当前展示请求序列，不允许某块区域在暂停期间单独变动。浏览器当前时间继续走动，但数据更新时间冻结。暂停时切换运行先清空旧快照、显示加载，再请求目标运行一次，保持暂停；运行别名、实体选择与旧运行响应同步清理。

仅当前台自动刷新模式超过 20 秒无成功数据响应时显示“更新延迟”和最后成功更新时间；请求明确失败显示断开/失败状态并保留旧快照。自动恢复时重新拉取，不重载整页。主动暂停或后台页暂停不触发延迟计时，前台恢复重新开始刷新与计时；历史快照和读取失败分别显示，不混成运行停止。

初次加载使用固定区域骨架；无资产、无发现、只有任务、图回退、数据部分载入均有独立状态。认证过期时清除带业务内容的画面并显示登录入口，不允许画面继续显示“实时更新”。不自动延长登录有效期。

coverage 的完整性、事件范围和暂停/延迟状态常驻底部状态区，不能随展示控制条一起隐藏。暂停截图仍保留数据时间，避免将其误作当前状态。

## 7. 展示控制与操作边界

控制条包含：运行选择、图类型、时间范围、标准/远距字号预设、暂停/恢复更新、手动刷新、聚焦巡览开关、全屏/退出全屏和返回工作台。

桌面无交互 8 秒后，仅收起控制条的辅助项；品牌、时间、数据状态、暂停标记持续显示。鼠标移入控制区或键盘聚焦时重新展开。保留一个可见的设置图标作为键盘入口；触屏不依赖 hover。不会在控件有焦点或弹层打开时自动隐藏。

Fullscreen API 只在点击动作内调用，监听 fullscreenchange 更新状态。浏览器拒绝或不支持时继续使用正常页面尺寸，显示局部提示；Esc 退出浏览器全屏后仍停留在大屏页面。

大屏不展示任务启动/停止、审批决定、流量重放、MCP/Skills 开关或环境配置入口。需要操作时进入工作台。它不是新的授权角色，仍需现有账号权限，不提供公开只读账号或匿名访问能力。

默认展示元信息与简短结论，不自动展开 Cookie、密钥、原始请求/响应、命令参数或环境变量。任务目标、主机名和发现摘要仍可能含业务信息；本期不承诺自动脱敏或公开分享，展示别名也不改变底层权限。

## 8. 分辨率与可读性

| 场景 | 布局规则 | 排版规则 |
| --- | --- | --- |
| 1920×1080 | 默认三列五行，主要内容无需滚动 | 品牌 30px，数值 40px，区标题 20px，正文 18px，辅助 14px |
| 2560×1440 / 3840×2160 | 保留三列关系，主图使用更多空间，不无限增加节点密度 | 提供操作者选择的远距预设：品牌 44px、数值 64px、区标题 28px、正文 26px、辅助 20px |
| 1440×900 / 1366×768 | 标准预设使用 16px 外边距、12px 间距、64/80/自适应/140/24px 行轨道，主图至少 280px 高；缩减列表条数 | 字号沿用标准档；超出时允许区域滚动。远距档在高度不足时允许纵向滚动 |
| 1024–1199px 横屏 | 两列：主图占第一行全宽，任务与发现放下方两列；允许页面纵向滚动 | 字号沿用标准档，不保留三列的 1200px 最小总宽 |
| 超宽屏 | 拓扑中心扩展，两侧内容不无限拉长；每侧最大 640px | 字号由展示预设决定 |
| <1024px 或竖屏 | 单列可滚动，主图优先、指标换行，控制条保持可达 | 使用标准固定字号；不缩放整张 1920px 画布 |

不用 `transform: scale()` 缩放整页，也不用 vw 字号；网格尺寸随容器变化，字号只由明确的标准/远距预设决定。4K 同时测试标准与远距两档，不假定设备像素数等于用户观看距离。

断点按浏览器实际 CSS 视口判断；1920/4K 面板在系统缩放或浏览器放大后可能落入较窄布局。1200–1439px 保持三列但使用紧凑网格间距；不根据物理像素数强制桌面布局。

品牌 Logo、数字和状态词使用对比度充足的前景；亮青绿主要用于当前选择，琥珀用于待处理，红色用于风险/失败。数值默认直接更新，避免滚动数字在频繁变化时降低可读性。

## 10. 实现边界与文件职责

| 文件 | 职责 |
| --- | --- |
| `web/src/components/WallboardView.tsx`，新增 | 独立大屏网格，复用统计和图形模块 |
| `web/src/components/WallboardControls.tsx`，新增 | 展示控制、FullScreen 状态与焦点恢复 |
| `web/src/styles/wallboard.css`，新增 | 大屏专属布局与标准/远距预设 |
| 主规格的 `situation.ts` | 共用指标、coverage、引用与事件分桶，不复制计算 |
| 现有 `useRuntimeDashboard.ts` | 增加受控暂停与在途请求取消能力，以保障冻结展示；保留工作台默认行为 |
| 主规格的 `GraphView` / `ActivityChart` | 通过展示配置减少文字与工具项，保留真实数据逻辑 |
| `App.tsx` / `useWorkbenchNavigation.ts` / `types.ts` | 注册 wallboard；在普通 WorkbenchShell 外渲染大屏，但仍在认证、主题与数据上下文内 |
| `language.tsx` | 大屏相关状态和控件双语文案，品牌仍为青玄 |

进入大屏时不挂载普通 Sidebar、Inspector、MCP/环境配置组件。退出后恢复正常工作台。暂停是该标签局部状态，不放到后端，也不在新标签间共享。图模式可使用白名单 `wallGraph=operation|reasoning|task`，字号用 `wallSize=standard|distance`；忽略未知值。显示别名不写 URL、localStorage 或服务器。

不为大屏新增 `/api/wallboard`、模拟数据服务、跨运行聚合和历史回放接口。数据延迟和截断通过现有 API 加主规格 coverage 展示。

## 11. 验收

1. 工作台可打开独立大屏，刷新 URL 后仍为同一运行；默认使用青玄品牌，无旧品牌可见标记。
2. 1920×1080 主内容无需整页滚动，3840×2160 远距预设清晰；1440×900、1366×768、超宽和竖屏不发生文字遮挡或按钮失联。
3. 在同一冻结快照下，大屏与工作台同口径指标完全一致；有相同数据来源与部分记录标记。
4. 空数据、只有 Task、只有候选资产、证据缺失、部分图、晚到响应、认证过期、网络失败分别呈现正确状态。
5. 暂停不会停止运行；暂停期间已发出的慢请求不能改变画面。恢复后刷新，手动刷新只更新一次，状态文字与画面一致。
6. Fullscreen API 成功、拒绝、不支持及 Esc 退出均不丢运行上下文；控制条可用键盘与触屏打开。
7. 三图切换、节点选择、工作台定位、可选聚焦巡览和 reduced-motion 行为可验证，图上无伪造边、随机变化或虚构攻击路径。
8. 大屏不提供变更后端状态的控件；analyst 不发审批请求；进入大屏不会加载环境配置或原始敏感报文。
9. 使用 Playwright 检查桌面与窄屏截图、Canvas 非空与交互像素变化。持续运行 30 分钟并切换图模式，确认图实例、计时器和缓存无持续增长；该长期验收在实现阶段运行。
10. 品牌图和可选背景正确加载；背景缺失时保持纯色可用。发布页不使用内部产品截图、请求包或未标注的演示假数据。

## 12. 顺序与交付

先完成主规格的主题、品牌、situation 派生和 coverage，再实现独立路由与布局，接入主图/指标/状态，补全暂停与全屏控制，最后接入可选美术并执行大屏验收。该页面是前端重构的独立子项目，可以单独编写 writing-plans 实施计划。

文档完成后交付可审阅规格；实际页面实施与图片生成另行开展。本规格不将大屏误记为已经可访问的功能。

本次已完成交叉审阅，修正了三列最小宽度、远距行高、全展示数据冻结、恢复失败重试和暂停延迟提示的约束；页面实现后的浏览器与长期运行验收仍按第 11 节执行。
