# 青玄 自动渗透agent：独立展示大屏设计

日期：2026-09-15。源码基线：`597509c`，已合入远端 `60a1753`。

状态：第二版设计规格，供实施前审阅。用户认为初版大屏不够炫酷，追加 FlyFish 与春秋 CCB2026 观赛页参考。本版将视觉方向升级为“立体态势舞台”，尚未实现页面，也未生成图片。

关联主规格：[青玄前端重构设计](2026-09-15-qingxuan-frontend-design.md)。品牌、数据口径、权限、图谱语义和主题基础沿用主规格；本规格补充独立展示场景。继续采用 Superpowers brainstorming 的设计与审阅流程。

## 1. 展示目标

大屏用于会议演示、项目展示和现场运行观察。观看者可以在几秒内看清产品名称、当前目标、资产与发现规模、关键关联路径和运行进展，不需要操作完整工作台。

页面名称为“态势大屏”，品牌完整名称为 **青玄 自动渗透agent**。它是同一应用中独立的只读展示页面，拥有专门布局，复用现有运行数据。工作台总览仍负责日常操作与深入分析。

| 维度 | 工作台总览 | 态势大屏 |
| --- | --- | --- |
| 场景 | 近距离反复操作、筛选、检查 | 远距离观看、讲解、持续展示 |
| 布局 | 导航、工具栏、可滚动内容与详情 | 无常驻侧栏，主图占中心，少量辅助区 |
| 信息 | 完整状态、筛选和操作入口 | 当前运行关键指标、短结论和近期变化 |
| 控制 | 任务控制、深入业务页面 | 全屏、暂停展示更新、刷新和返回工作台 |
| 视觉 | 紧凑文字与表格 | 居中品牌页头、立体资产舞台、事件聚焦、远距排版 |

独立浏览器页与 Fullscreen API 是两种能力：不用浏览器全屏也能直接打开大屏；用户点击后才请求浏览器全屏。不新增独立后端部署、不新增公开匿名分享链接。

- 官方 [地图路线图缩略图](https://github.com/CloudWise-OpenSource/FlyFishComponents/blob/main/components/地图路线图/thumbnail/icon.png) 可见多层轮廓和空间厚度；[旋转组件源码](https://github.com/CloudWise-OpenSource/FlyFishComponents/blob/main/components/旋转组件/src/total/index.less) 可确认内外环持续旋转。参考其层次与动静配合，不复制地图、品牌或业务数据。在线 demo 本次返回 502，未验证在线交互。
- [春秋 CCB2026 入口](https://match.ichunqiu.com/ccb2026)：作为用户指定的观赛方向参考。当前访问验证与限制记录于调研文档；没有实际看到的比赛画面、排行榜和动效不写成已验证事实。

| 方案 | 效果与代价 | 本版选择 |
| --- | --- | --- |
| A. 立体态势舞台 | 青玄居中页头、真实资产立体拓扑、重点事件联动；需增加独立 Three.js 渲染与降级 | 推荐，回应更强的展示感；作为本版待审方案 |
| B. 二维科技看板 | 加强切角结构和图形配色，沿用全部 Cytoscape；成本较低，但空间感变化有限 | 保留为低性能设备的降级形式，不作为主视觉目标 |
| C. 地球攻防竞赛场 | 视觉宏大，但当前没有地域、参赛队伍与竞赛计分契约 | 不采用，不以假地图、战队排名或随机攻击线凑效果 |

大屏与工作台采用不同的视觉密度。工作台的克制动效规则不限制本页的空间舞台与装饰运动；品牌和数据语义仍共用。使用开源项目作为设计参考不等于引入 FlyFish 编辑器或搬运其素材源码。

## 2. 入口与运行上下文

- 新增 `view=wallboard`，与主规格的 `runtimeDir`、`range`、`from`、`to` 共用解析。
- 顶栏增加带 Tooltip 的 `Monitor` 图标入口，当前运行加载有效后可打开。点击在新标签打开，使用 `noopener`，原工作台保持当前视图；浏览器不允许打开时提供同页链接。
- 新标签沿用同源认证 Cookie。登录过期进入现有认证流程，认证后恢复大屏 URL；不在 URL 附带 Cookie、令牌或秘密参数。
- 可选择已有历史运行展示其当前持久快照。历史快照标为“历史运行快照”，不命名为历史回放。
- 直接打开但缺少 runtimeDir 时，沿用 URL > 既有运行存储 key > 默认目录的选择规则；无法取得运行数据时显示运行选择与返回工作台入口，不展示模拟默认数据。
- 提供“返回工作台”入口，默认回到同一运行的 overview。通过节点“在工作台查看”进入 operation/reasoning/task 并携带 nodeId，符合主规格的真实引用规则。

## 3. 1920×1080 主布局

```text
+----------------------------------------------------------------------------+
| 当前目标 / 运行别名     [品牌图形] 青玄 自动渗透agent      运行状态 / 时钟    |
|                         切角分层页头与两翼短光轨                           |
+----------------------------------------------------------------------------+
|          主机          服务          漏洞发现        成功利用    任务完成   |
+------------------+--------------------------------------+------------------+
| 任务推进         |              当前快照 · 资产          | 发现与证据       |
| 状态分布 / 阻塞  |                                      | 重点结论         |
|                  |       立体资产节点 / 真实关系         | 时间 / 证据引用  |
| Agent 最近活动   |          斜俯视空间舞台               |                  |
| Planner          |                                      | 待处理事项       |
| Executor         |      [节点底座] --- [关联节点]        | 阻塞 / 失败      |
| Observer/Runtime |         低对比精密地面                |                  |
+------------------+--------------------------------------+------------------+
| 已加载事件趋势   | 当前焦点：类型 / 短结论 / 来源 / 时间 | 最近关键事件     |
+----------------------------------------------------------------------------+
| 数据范围 / 部分记录 / 数据更新时间          暂停或延迟      [展示控制]     |
+----------------------------------------------------------------------------+
```

外边距 24px、分区间距 16px。标准预设五行：品牌区 112px、指标区 96px、中心区自适应、底部 180px、状态区 36px；1920×1080 时中心区为 544px。中心三列为 `minmax(240px, 1fr) minmax(620px, 2.8fr) minmax(280px, 1.1fr)`，约 20%/57%/23%。底部沿用三列，中央事件焦点与主舞台对齐。

远距预设改为品牌区 144px、指标区 128px、底部 240px、状态区 44px；1920×1080 时中心区为 412px。目标两行各 34px，品牌主行 72px、副行 32px；指标数值行 80px、标签行 32px。侧区按固定行高减少可见条数，不通过压低字号强塞内容。

主舞台是无框的连续场景，不嵌在预览卡里。Three.js 画布占据整块中央区，地面透视线与页面底层美术连续；侧区使用贴边标题短线和半透明连续底面，不做悬浮卡片。切角装饰集中在页头和舞台下沿，不给每个列表再套发光边框。所有数据面板按网格占位，装饰层 pointer-events 为 none。

右侧重点发现最多 4 条，每条两行结论、一行元信息；远距或短屏按可用高度减少条数，余数显示“另有 N 条已加载发现”。左侧角色区最多四行，包含 Runtime，均为最近事件摘要。底部最近事件最多 3 条，显示真实时间，不展示工具原始输出。列表和图形数据文字不受页头装饰裁切。

页头使用独立三列，左右 `minmax(0, 1fr)`，中间品牌列标准 640px、远距 720px。左翼目标最多两行，右翼为状态、时间与时区，不能跨入品牌列；品牌“青玄”是第一视觉信号，副行“自动渗透agent”保持真实文字。完整目标通过控制条详情查看。展示短名称仅是当前标签页别名，不改原始目标、不保存服务器。窄屏品牌、目标和状态分行，见第 8 节。

## 4. 主视觉与动态规则

### 4.1 立体资产舞台

默认资产模式使用 Three.js 构建立体拓扑：斜俯视正交相机约 35 度俯角，实体节点呈现在低矮精密地台上。不是世界地图、机房写实模型或自由飞行游戏。Host 用方柱底座，Service 用低矮六角底座，WebEndpoint 用薄片节点；类型仍由 Lucide 图标与文字确认，形状不代表风险。

复用 `graph.ts` 的 operation 投影、ELK 布局结果、稳定节点 ID、真实边与语义颜色；将二维坐标映射到地面的 X/Z 轴，Y 轴只用于视觉层次，不代表风险分数、网络层级或物理位置。Host 等实体之间只有原始边，不推断网段和地理归属。漏洞关联通过已解析到实体 ID 的证据/引用索引标记；缺失关联时只在右栏展示发现，不在舞台上虚构连接。

地台表面、细描边、节点侧面与少量边缘发光形成纵深。默认无昂贵全场景 Bloom 和实时阴影；文字不参与发光或后处理。顶部指标和侧区均为清晰 DOM，不把整屏做成 Canvas 截图。中央场景不是装饰图，而是同一批真实资产的可选择、可缩放展示。

### 4.2 配色与观看层次

采用独立深色主题，不改变工作台已保存的深浅偏好。基底为近黑 `#090D10`、石墨 `#161C21`；主文字冰白 `#F1F3F5`；青绿 `#53D6BD` 表示选择/执行，冰蓝 `#7DB7FF` 表示资产，琥珀 `#F2C066` 表示等待，珊瑚红 `#FF8087` 表示风险/失败，成功沿用 `#83D98E`。不做满屏海军蓝或全部青色文字。背景约占视觉面积 70%，亮色集中于品牌、数据和当前焦点；这个比例是美术目标，不改变语义色映射。

整屏同时只有一个高亮焦点：有新发现时为对应实体或右侧结论，没有新发现时为用户选中实体。标题装饰可常亮但亮度低于数据；不存在每块区域同步闪烁。标准/远距仅改变排版密度。

### 4.3 图模式与交互

提供“资产 / 推理 / 任务” Segmented，默认资产。资产模式默认立体；推理/任务仍用 Cytoscape 的专业二维关系表达，不强行将证据链与任务依赖变成 3D。三种模式沿用同一中央区域、配色与标题。图切换只改变中央内容，顶部指标仍为当前运行快照。

资产舞台最多 60 个已加载节点、120 条原始边，优先选中节点、漏洞关联资产及一跳邻居，余量按时间与 ID 稳定补齐。边按选中实体邻边、更新时间与 ID 选取；端点必须可见，剩余节点/边数量持续显示，不冒充全图。推理/任务也采用最多 60 节点、120 边的局部投影；已加载范围、当前可见范围与后端 coverage 分别说明。

鼠标可选择节点、缩放和平移；立体模式仅允许有限方位调整，俯角约 25–55 度，不允许翻到地台下方。提供复位视角图标和可访问实体列表，键盘不必操作 3D 才能查看信息。资产标签用 DOM 投影到安全区，默认最多 12 个，选中标签优先；碰撞时隐藏低优先级标签，不能盖住指标或侧栏。摘要移到下方当前焦点区，最多三行，提供工作台定位链接。轮询保留镜头和选择，只有结构变化才调整局部布局；同一运行刷新不重新入场。

缺少资产时只显示无资产状态与静态地面，不用示意节点填空；只有任务数据时可手动切到任务图。实体从快照消失则提示未载入，不默默选中其他对象。首次布局稳定后统一适应场景范围；ResizeObserver 变化只调整画布和相机，不重建整套数据。

### 4.4 动效编排

“炫酷”由立体构图、分层入场和一次明确的事件聚焦组成。允许有展示性装饰运动，但必须与业务事件反馈分开：

| 动效 | 触发与表现 | 限制 |
| --- | --- | --- |
| 首次入场 | 页头 200ms 淡入，指标与侧区随后显现，场景在布局完成后 600–900ms 从低亮度进入 | 整段 <=1.4s；不遮住已可用数据，不随轮询重播，不滚动数字凑加载 |
| 舞台环境 | 低对比地台外围刻线每 24s 平稳移动一个周期，页头两翼可有很短的缓慢亮度过渡 | 仅装饰轨道，不贴在实体边上；无雷达扫描、光球、散景粒子、全屏闪白；可关闭 |
| 资产或状态变化 | 已完成首次基线后，稳定 ID 新增或实际状态变化产生 600–900ms 轮廓强调 | 每批最多 5 个，其余只计数；不将首次载入的已有资产演成刚发现 |
| 有关联的执行事件 | 源事件明确引用可见实体与原始边时，沿该边短暂流动 700–1200ms | 无方向契约时只做全边亮度强调；没有实体引用则只更新事件区，不猜测路径 |
| 证据支持的关键发现 | 右侧对应条目短暂强调，底部焦点展示结论与时间，相关资产底座同步高亮 | 漏洞/成功利用符合第 5 节；不弹全屏胜利画面，不改变用户镜头 |

首次加载、切换运行和恢复刷新都先建立新基线，不播放离开期间累积事件。新事件按稳定 ID 去重，同一事件只表现一次；缺少稳定身份的记录只静态展示，不用数组下标触发动效。同时最多 3 条边运动。事件焦点显示 6 秒，批量只选最新一条符合条件的发现，其余显示新增数，不排队补播。用户已选中实体时保留用户焦点，新发现只强调右侧；点击才更换底部焦点。

仅自动刷新、运行明确进行中且数据新鲜时播放业务事件动效；历史快照、运行状态未知、暂停、断线或延迟时不播放。暂停同时停止环境运动与巡览，时钟仍运行；隐藏页面停止渲染循环。reduced-motion 或“动效关闭”时只显示静态重点样式，无入场位移、轨道运动或镜头过渡。环境运动没有在线/任务执行含义，静态历史页可保留材质但不运动。

首版不自动轮换运行、不自动切换三图、不自动滚动长列表。可另提供默认关闭的“聚焦巡览”：每 15 秒聚焦下一个已显示的发现关联节点，最多 5 个候选；不跨图、不推断攻击路径。鼠标或键盘交互立即暂停巡览，操作者显式恢复。巡览是视角变化，不声称新事件发生。

巡览关闭是默认值；开启后也只允许小幅平移/缩放，不持续绕场旋转。reduced-motion 时使用无过渡的焦点选择，暂停展示、历史快照或数据延迟时停止巡览。所有动效均可被用户关闭，不加入声音。

## 5. 展示指标与数据边界

| 大屏信息 | 数据规则 | 受限时的展示 |
| --- | --- | --- |
| 主机、服务 | 已加载 operation 的对应类型按 ID 去重 | 标注已加载，不称全量资产 |
| 漏洞发现 | Vulnerability 且证据引用非空 | 无统一严重性时不显示“高危数量” |
| 成功利用 | Exploit 且 status=succeeded、证据引用非空 | 不把所有利用节点当成功 |
| 任务完成 | 已加载 completed / 非 archived Task | 未识别状态保留未知；分母为空不显示 100% |
| 角色最近活动 | 最新角色事件 | 不作为实时 Agent 在线心跳 |
| 待处理 | 阻塞、失败分组，管理员可显示当前运行审批数量 | analyst 不请求审批；不以 0 暗示无权限的数据 |
| 事件趋势 | 已加载事件按真实时间分桶，最多 60 桶 | 未覆盖范围不补零，部分记录标记持续可见 |

所有数据复用主规格的 `situation.ts` 与 coverage 传播规则。大屏不单独计算第二套“风险指数”。SQLite 图本身的 1200/2400 上限、700 事件窗口、报告/产物上限同样生效。

时间选择仅作用于事件趋势和近期事件，拓扑与上方资产/发现统计持续标明“当前快照”。选择旧运行不意味着能按任意时间恢复历史图。

当前时间由浏览器时钟显示并附时区，数据更新时间单独显示。时钟每秒更新只重绘时钟组件，不能触发图谱重建、数据请求或整页动画。

## 6. 刷新、暂停和异常

大屏单个标签只启动一套运行数据轮询，复用 `useRuntimeDashboard` 的请求结束后 5 秒刷新和隐藏标签暂停行为；与另一个工作台标签之间不新增跨标签轮询协调服务。

“暂停更新”冻结大屏当前快照，取消在途状态请求并阻止晚到响应覆盖画面，同时暂停聚焦巡览。暂停只改变展示，不停止 Agent 或后端任务；控制 Tooltip 写明含义。恢复立即进入自动刷新模式并请求一次，失败仍在请求结束后按 5 秒间隔重试；保留合理的图视口。手动刷新在暂停时仅取一次各来源数据，之后继续暂停；该次请求失败也保留暂停并显示局部错误。

冻结范围包括运行展示状态、指标、图谱、事件、coverage 和可见审批计数；各来源请求均服从当前展示请求序列，不允许某块区域在暂停期间单独变动。浏览器当前时间继续走动，但数据更新时间冻结。暂停时切换运行先清空旧快照、显示加载，再请求目标运行一次，保持暂停；运行别名、实体选择与旧运行响应同步清理。

仅当前台自动刷新模式超过 20 秒无成功数据响应时显示“更新延迟”和最后成功更新时间；请求明确失败显示断开/失败状态并保留旧快照。自动恢复时重新拉取，不重载整页。主动暂停或后台页暂停不触发延迟计时，前台恢复重新开始刷新与计时；历史快照和读取失败分别显示，不混成运行停止。

初次加载使用固定区域骨架；无资产、无发现、只有任务、图回退、数据部分载入均有独立状态。认证过期时清除带业务内容的画面并显示登录入口，不允许画面继续显示“实时更新”。不自动延长登录有效期。

coverage 的完整性、事件范围和暂停/延迟状态常驻底部状态区，不能随展示控制条一起隐藏。暂停截图仍保留数据时间，避免将其误作当前状态。

## 7. 展示控制与操作边界

控制条包含：运行选择、图类型、时间范围、标准/远距字号预设、暂停/恢复更新、手动刷新、全屏/退出全屏和返回工作台。设置弹层提供动效开关、聚焦巡览、资产画面“立体/平面” Segmented；推理/任务模式不显示无效的立体选项。常用命令使用 Lucide 图标，触屏点击面积至少 44×44px。

桌面无交互 8 秒后，仅收起控制条的辅助项；品牌、时间、数据状态、暂停标记持续显示。鼠标移入控制区或键盘聚焦时重新展开。保留一个可见的设置图标作为键盘入口；触屏不依赖 hover。不会在控件有焦点或弹层打开时自动隐藏。

Fullscreen API 只在点击动作内调用，监听 fullscreenchange 更新状态。浏览器拒绝或不支持时继续使用正常页面尺寸，显示局部提示；Esc 退出浏览器全屏后仍停留在大屏页面。

大屏不展示任务启动/停止、审批决定、流量重放、MCP/Skills 开关或环境配置入口。需要操作时进入工作台。它不是新的授权角色，仍需现有账号权限，不提供公开只读账号或匿名访问能力。

默认展示元信息与简短结论，不自动展开 Cookie、密钥、原始请求/响应、命令参数或环境变量。任务目标、主机名和发现摘要仍可能含业务信息；本期不承诺自动脱敏或公开分享，展示别名也不改变底层权限。

### 10.1 渲染预算与降级

- 画面目标 30fps，交互顺畅优先，不追求空转 60fps。1080p 有效 DPR 上限 1.5，4K 上限 1；renderer 大小由 CSS 容器和 DPR 共同限制，不按硬件像素无限放大。
- 默认无实时阴影、全场景 Bloom、粒子雨与写实模型；底座共享几何和材质。字体与数据标签保留 DOM 清晰度。开始/结束动画才需要活动渲染，无运动状态使用按需渲染。
- 仅在前台有连续动画或持续交互的有效采样窗口内评估帧率；空闲、暂停、隐藏、reduced-motion 静态阶段不计入。有效连续 5 秒平均低于 24fps，先停环境运动并降低 DPR；调整后若仍有运动/持续交互，再采样 5 秒，仍低于阈值则切为 Cytoscape 平面资产图。若转为空闲，不因停止出帧而降级。WebGL 初始化失败、上下文丢失、用户手动选择或窄屏默认使用平面。保留运行、选择与指标，回退不自动反复升级，用户显式重试才恢复 3D。
- 平面图同样使用青玄页头、外围信息区、事件焦点与真实关系，不能降级成无内容占位。切图后旧渲染器停止动画并释放资源，任一时刻只保留一个中央图实例。
- 运行切换重建演示基线并清空旧事件 ID/焦点；旧运行较慢响应不能覆盖当前运行。隐藏时暂停 RAF、展示计时器、拾取和请求，保留场景、镜头与选择；重新可见时先恢复数据基线，不补播动画。切换渲染器、退出或认证过期时才销毁监听与渲染资源，释放 geometry/material/texture/render target/controls。释放规则参考 [Three.js 官方资源管理说明](https://threejs.org/manual/en/how-to-dispose-of-objects.html)。

不为大屏新增 `/api/wallboard`、模拟数据服务、跨运行聚合和历史回放接口。数据延迟和截断通过现有 API 加主规格 coverage 展示。

## 11. 验收

1. 工作台可打开独立大屏，刷新 URL 后仍为同一运行；默认使用青玄品牌，无旧品牌可见标记。
2. 1920×1080 主内容无需整页滚动，3840×2160 远距预设清晰；1440×900、1366×768、超宽和竖屏不发生文字遮挡或按钮失联。
3. 在同一冻结快照下，大屏与工作台同口径指标完全一致；有相同数据来源与部分记录标记。
4. 空数据、只有 Task、只有候选资产、证据缺失、部分图、晚到响应、认证过期、网络失败分别呈现正确状态。
5. 暂停不会停止运行；暂停期间已发出的慢请求不能改变画面。恢复后刷新，手动刷新只更新一次，状态文字与画面一致。
6. Fullscreen API 成功、拒绝、不支持及 Esc 退出均不丢运行上下文；控制条可用键盘与触屏打开。
7. 三图切换、立体/平面切换、节点选择、工作台定位、可选聚焦巡览和 reduced-motion 可验证；图上无伪造边、随机变化或虚构攻击路径。首次载入、恢复和同一轮询重复事件不重播发现；无关联事件不产生路径动画。
8. 大屏不提供变更后端状态的控件；analyst 不发审批请求；进入大屏不会加载环境配置或原始敏感报文。
9. 使用 Playwright 检查 1920×1080、3840×2160、1366×768、1024×768、390×844 截图；对中央业务 Canvas 做非背景像素检测与选择前后像素比较，不以背景图片或存在 canvas 元素代替非空证明。开启环境动效时验证其区域像素变化；暂停无交互时排除时钟后画面稳定。reduced-motion 使用固定快照、无交互验证像素稳定，另注入新数据验证数字/节点立即更新而无过渡，不将减少动效当暂停刷新。确认模型、纹理加载且不遮挡 DOM，模拟 WebGL 失败和上下文丢失验证平面降级。
10. 在记录了浏览器、硬件、DPR 的测试机上以最大展示节点/边持续运行 30 分钟，切换图与运行各 20 次。记录帧率、renderer.info 和缓存大小，无持续增长；低于预算须验证自动降级，不能仍宣称高质量 3D 达标。该长期验收在实施阶段执行。
11. 品牌及三项美术的尺寸、加载失败、字标对比度通过检查；不使用内部截图、请求包或未标注的演示假数据。发布版数据来自实际接口，测试 fixture 不作为生产回退。
12. 视觉验收：首屏明确见到“青玄”、中央立体节点与地台纵深、左右有组织的信息区、一次真实事件的局部高亮；不是只有普通平面图加深色背景。准备同一快照的标准/远距/平面降级截图供用户审阅，功能通过与视觉认可分别记录。

## 12. 顺序与交付
