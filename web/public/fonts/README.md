# Qingxuan Wallboard Fonts

These fonts are hosted locally; the wallboard does not call a remote font service.

- `SmileySans-Oblique.ttf.woff2`: unmodified Smiley Sans v2.0.1 release file, used for Chinese display headings. [Upstream release](https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1). License: `SmileySans-OFL.txt`. The full original file preserves its reserved font names.
- `chakra-petch-medium.ttf`: Chakra Petch Medium, used for numeric instruments and short Latin labels. [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/chakrapetch). License: `ChakraPetch-OFL.txt`.
- Rajdhani and the Noto Sans SC subset are retained from the earlier visual revision; the current wallboard uses the two fonts above.

Fonts are presentation assets only. All displayed counts, dates, labels and statuses remain real text.
